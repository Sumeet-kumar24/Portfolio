## ✨ Features

- **Modern UI/UX:** Clean, dark-themed glassmorphism design with `emerald` and `violet` subtle gradients.
- **Smooth Animations:** Scroll-triggered fade-ins, active navigation underlines, and a beautiful hero loading sequence using `framer-motion`.
- **Fully Responsive:** Seamlessly adapts to mobile, tablet, and desktop screens.
- **Dynamic Sections:** Includes About, Skills, Projects, Training, Education, and Contact sections.
- **Clean Codebase:** Built as a single-page React application with Vite for fast builds.

## 🛠️ Tech Stack

- **Framework:** [React 18](https://reactjs.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 💻 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (version 16 or higher) and `npm` installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. Navigate to the project directory:
   ```bash
   cd your-repo-name
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### Building for Production

To create a production-ready build:

```bash
npm run build
```

The output will be generated in the `dist/` directory, which can be deployed to any static hosting service.

## 📁 Project Structure

- `src/`
  - `Portfolio.jsx`: The main React component containing the entire layout, sections, and data.
  - `main.jsx`: The entry point of the React application.
  - `index.css`: Global styles and Tailwind directives.
- `tailwind.config.js`: Custom theme and color configurations.
